# Чеклист оператора — ТЗ 70 + feedback 06.08.2026

Проверка на **dev** или после update на work. Базу не затирать.

## 0. После update на work (ops)

1. `scripts\update.ps1` — **не** трогает `data\app.db`.
2. Один раз: `request-processor db-role --set work --source "рабочий ПК"`.
3. Заголовок окна: `[WORK]` (не `[DEV]`).
4. Zip: `request_processor_0.9.1_YYYYMMDD.zip` **без** app.db.

## 1. Свободный текст («Текст…»)

1. **Заявка** → **Текст…**
2. Вставьте письмо, например:
   - U/UTP cat 5e … + **КССПП 5е 2х2х0,52**
   - или МГЛФ / КАГЭ
3. **Разобрать** (кнопки внизу видны).
4. **Ожидание:** нет ошибки main thread; марки в таблице; поле «документ» **не** «стоимостью».

## 2. Заказчик и производитель

1. Autocomplete из справочника; «Производитель = заказчик» при необходимости.
2. **Подтвердить заявку** → имена в КП/заказе (не «заказчик», не login Windows).

## 3. Расчёт → КП → пакет

1. Марка → **В расчёт** → КП → **Пакет**.
2. Имя заказчика в папке/КП.

## 4. Справочник «Марки»

1. Двойной клик / **Редактировать…** → сохранить → **В расчёт**.

## 5. Организации — поиск

1. Вкладка **Организации**.
2. В поиске: `тольят` (строчными) → должен найти «Тольяттинский…».
3. `спец` → «Спецкабель».

## 6. Адрес — Ctrl+C

1. **Заявка** → поле **Адрес** (или карточка org).
2. Выделите адрес → **Ctrl+C** (RU и EN раскладка).
3. **Ожидание:** вставляется в Word/Блокнот; **текст в поле не меняется** (не вставка).

## 7. Логи и старт

1. Меню → папка логов → `app_ДАТА.log`.
2. Fallback: `%LOCALAPPDATA%\Lab_request\logs`.
3. При запуске: в bat — сообщение «запуск…»; splash/полоса; в логе `t_pre_splash` / `t_import` / `ready total`.
4. Если cold start >15 с — предпочтительно **локальная** копия приложения (data может остаться на NAS).
