# Чеклист оператора — ТЗ 70 (org / free-text / марки)

Проверка на **dev** или после update на work. Базу не затирать.

## 1. Свободный текст («Текст…»)

1. Откройте **Заявка** → **Текст…**
2. Вставьте письмо (например МГЛФ / КАГЭ / три строки ВВГ + U/UTP + КВПФэМ).
3. Нажмите **Разобрать** (кнопки внизу окна видны).
4. **Ожидание:** нет ошибки про main thread; в таблице появились марки; можно править.

## 2. Заказчик и производитель

1. В полях **Заказчик** / **Производитель** начните вводить имя из справочника — появятся подсказки.
2. Выберите организацию **или** введите новое имя вручную.
3. При необходимости включите **«Производитель = заказчик»**.
4. **Подтвердить заявку**.
5. **Ожидание:** в КП и в заказе — введённые имена (не «заказчик»); в списке заказов org не пустые, если org сохранились.

## 3. Расчёт → КП → пакет

1. Марка → **В расчёт** → посчитайте → **КП**.
2. **Заказы** → **Пакет документов**.
3. **Ожидание:** в имени папки/КП — имя заказчика; в заявке Word — заказчик и производитель из шага 2.

## 4. Справочник «Марки»

1. **Марки** → двойной клик или **Редактировать…**
2. Поменяйте, например, документ/размер → **Сохранить**.
3. **В расчёт** — в поле должна быть **новая** строка обозначения.

## 5. Логи

1. Меню → папка логов.
2. Есть файл `app_СЕГОДНЯШНЯЯ_ДАТА.log`.
3. Если `data\logs` на сети недоступен — смотрите `%LOCALAPPDATA%\Lab_request\logs`.

## 6. Версия / обновление

- Zip: `request_processor_0.9.1_YYYYMMDD.zip` (без app.db).
- Work: `scripts\update.ps1` — БД не трогать.
- После update: один прогон пунктов 1–3 на реальной заявке.
